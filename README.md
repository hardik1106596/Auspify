# Full Stack Development Internship Projects

A collection of four web application projects developed as part of my Full Stack Development Internship at **Auspify Technologies**. These projects focus on practical full-stack development, responsive UI design, REST APIs, database management, authentication, and real-world application features.

## Projects

| Task | Project | Description |
|---|---|---|
| 03 | Expense Tracker Web Application | Track income, expenses, and financial summaries. |
| 04 | E-Commerce Website | Browse products, manage a shopping cart, and handle orders. |
| 05 | Job Portal Web Application | Connect job seekers with employment opportunities. |
| 06 | Learning Management System | Provide an online platform for courses and learning resources. |

---

## Task 03 — Expense Tracker Web Application

A personal finance application designed to help users manage income, expenses, and financial records.

**Key Features**
- User registration and authentication
- Add, edit, and delete transactions
- Categorize income and expenses
- Dashboard displaying balance, income, and expenses
- Financial reports and charts
- Search and filter transactions

**Technologies:** React.js, CSS3, Node.js, Express.js, MongoDB, JWT

## Task 04 — E-Commerce Website

An online shopping application that allows users to explore products and manage their shopping experience.

**Key Features**
- Product listings and product details
- Search and category filtering
- Shopping cart management
- User registration and login
- Order placement and order history
- Responsive user interface
- Backend APIs and database integration

**Technologies:** React.js, CSS3, JavaScript, Node.js, Express.js, MongoDB

## Task 05 — Job Portal Web Application

A web application designed to help job seekers discover opportunities and enable employers to manage job listings.

**Key Features**
- User registration and login
- Browse and search job listings
- Filter jobs by category, location, and type
- View job descriptions and requirements
- Post and manage job openings
- Submit job applications
- Manage application status

**Technologies:** React.js, CSS3, Node.js, Express.js, MongoDB

## Task 06 — Learning Management System

An online learning platform designed to organize educational content and help learners access courses.

**Key Features**
- User authentication
- Browse and view available courses
- Course details and learning resources
- Enroll in courses
- Track learning progress
- Manage course content
- Responsive dashboard for learners

**Technologies:** React.js, CSS3, Node.js, Express.js, MongoDB

## Getting Started

1. Clone this repository.
2. Open the folder of the project you want to run.
3. Install the required dependencies.
4. Configure the environment variables and database.
5. Start the frontend and backend servers using the project's README instructions.

```bash
git clone YOUR_REPOSITORY_URL
```
