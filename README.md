# Auspify Internship Projects

A collection of full-stack web application projects developed as part of a development internship at **Auspify Technologies**. Each application has its own frontend and backend setup.

## Projects

| Task | Project | Description |
|---|---|---|
| 03 | [Expense Tracker](./expense-tracker/) | Track income, expenses, and financial summaries. |
| 04 | [ShopVerse E-Commerce](./shopverse/) | Browse products, manage a shopping cart, and handle orders. |
| 05 | [CareerConnect Job Portal](./careerconnect/) | Search, filter, and apply for employment opportunities. |
| 06 | [Auspify LMS](./LMS/) | Explore courses, enroll, and track learning progress. |

---

## Task 03 — Expense Tracker Web Application

A personal finance application designed to help users manage income, expenses, and financial records.

**Key Features**
- User registration and authentication
- Add, edit, and delete transactions
- Categorize income and expenses
- Dashboard displaying balance, income, and expenses
- Financial reports and charts
- Search and filter transactions

**Technologies:** React.js, CSS3, Node.js, Express.js, MongoDB, JWT

## Task 04 — ShopVerse E-Commerce

An online shopping application that allows users to explore products and manage their shopping experience. See the [ShopVerse README](./shopverse/README.md) for setup instructions.

**Key Features**
- Product listings and product details
- Search and category filtering
- Shopping cart management
- User registration and login
- Order placement and order history
- Responsive user interface
- Backend APIs and database integration

**Technologies:** React.js, CSS3, JavaScript, Node.js, Express.js, MongoDB

## Task 05 — CareerConnect Job Portal

A full-stack job portal designed to help job seekers discover and apply for opportunities while employers manage listings and applications.

**Key Features**
- User registration and login
- Browse and search job listings
- Filter jobs by category, location, and type
- View job descriptions and requirements
- Post and manage job openings
- Submit job applications
- Manage application status

**Technologies:** React.js, CSS3, Vite, Node.js, Express.js, MongoDB, JWT

See the [CareerConnect README](./careerconnect/README.md) for setup instructions.

## Task 06 — Learning Management System

A full-stack learning platform with learner and instructor accounts, course catalogs, enrollment, progress tracking, quizzes, and assignments.

**Technologies:** React.js, CSS3, Vite, Node.js, Express.js, MongoDB, JWT

See the [LMS README](./LMS/README.md) for setup instructions.

## Repository Structure

The repository root contains this overview and three independent applications: `expense-tracker/`, `shopverse/`, and `careerconnect/`. Each project contains its own source code and setup instructions.

## Getting Started

1. Clone this repository.
2. Open the folder of the project you want to run.
3. Install the required dependencies.
4. Configure the environment variables and database.
5. Start the frontend and backend servers using the project's README instructions.

```bash
git clone YOUR_REPOSITORY_URL
```
